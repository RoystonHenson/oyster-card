# OysterCard___

As a customer,
I want money on my card,
so I can use public transport.

As a customer,
I want to add money to my card,
so I can keep using public transport.

As a customer,
I want a maximum limit(£90) on my card,
so I can protect my money from theft or loss.

As a customer,
I want my fare deducted from my card,
so I pay for my journey.

As a customer,
I want to touch in and out,
so I can get through the barriers.

As a customer,
I want to have the minimum amount(£1)
for a single journey on my card,
so I can pay for my journey.

As a customer,
when my journey is complete and I touch out, I want the correct fare deducted from my card,
so I can pay for my journey.

As a customer,
I want to see to all my previous trips,
so I know where I have been.

As a customer,
I want journeys which were not completed correctly to also be recorded,
so I know where I incurred a penalty charge.

# Journey___

As a customer,
I want to know where I've travelled from,
so I can pay the correct fare for my journey.

As a customer,
I want to know where I've travelled to,
so I can pay the correct fare for my journey.

As a customer,
I want a penalty charge deducted if I fail to touch in or out,
so I am charged correctly.

# Station___

As a customer,
I want to know the name of a station,
so I know where I've travelled from.

As a customer,
I want to know what zone a station is in,
so I know how far I have travelled.

---

As a customer,
I want to have the correct fare calculated,
so I can be charged the correct amount.
